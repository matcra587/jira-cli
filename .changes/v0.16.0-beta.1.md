## [0.16.0-beta.1](https://github.com/matcra587/jira-cli/releases/tag/v0.16.0-beta.1) — 2026-10-26

> [!NOTE]
> This beta does not include the `tui` subcommand. Use `issue list --jql` or
> `issue list --saved` in place of the former `search` commands.

### Breaking Changes

- Request issue-view metadata explicitly with `--expand`; default views retain all native fields without requesting metadata expansions.
- Trim cache priming and refresh receipts by removing `force`, `unbounded`, `ttl_minutes` and `age_seconds`; retain native items, collection limits, freshness state and write outcomes.

### Changed

- Shorten issue help and route detailed workflows through embedded guides. Use `jira agent guide migrate-scripts` to adapt legacy commands and output handling.

### Fixed

- Let explicit raw and saved issue queries override the default board without a cached snapshot, while preserving current-account scope. Clarify how to warm retained board defaults after migration.
- Keep literal times, repeated colons and unfinished directives in contiguous Markdown text nodes without changing marks or native ADF preservation.
- Return complete requested relationship sentences after issue-link type resolution, including validated previews and failed-write receipts. Keep bare previews unresolved and write outcomes separate.
- Keep JSON and compact failures in one structured stdout frame without duplicate human diagnostics on stderr. Preserve human-mode advice and output-destination error reporting.

### Dependencies

- Update Go dependencies and tool modules, including clib 0.8.2, koanf 2.4.1 and docent 0.4.1, and refresh transitive dependencies.
- Run development scripts and documentation builds on Python 3.15 and modernize script file handling and test cleanup.
- Update development tools and CI actions, including hk 2.8.1, golangci-lint 2.15.0, GoReleaser 2.19.0 and Zensical 0.0.72.
