## [0.16.0](https://github.com/matcra587/jira-cli/releases/tag/v0.16.0) — 2026-11-15

This is the stable release of the 0.16 line, including the restored dashboard and native Jira output contracts developed in the prereleases.

When upgrading from 0.15, review the [0.16 migration and breaking changes](https://github.com/matcra587/jira-cli/releases/tag/v0.16.0-beta.0) and run `jira agent guide migrate-scripts`. Preview legacy configuration conversion with `jira config migrate --source FILE`; unsupported dashboard settings remain visible for review, or can be retained with `--defer-tui`. Existing flat configurations remain readable.

The following changes are new since beta.4.

### Added

- Discover documented API endpoints and complete method-specific path templates offline from the bundled Platform and Agile catalog, without credentials or cache warmup.
- Migrate supported legacy dashboard preferences into active settings, and suggest a migration preview when commands encounter an old configuration format.

### Dependencies

- Build with Go 1.27.4 and require the patched compiler for source installations.
